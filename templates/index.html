💡 How the POST Flow Works

  • 1. UI Event: User clicks Generate Profile Card. JavaScript captures form values into a JSON object.
  • 2. HTTP POST: Dispatched using fetch('/api/profile/generate', { method: 'POST', body: ... }).
  • 3. Backend Processing: Flask validates fields, sanitizes URLs, creates initials avatar if needed, and computes stats.
  • 4. Response & Rendering: Backend returns 200 OK with structured JSON. The UI renders the formatted card!
